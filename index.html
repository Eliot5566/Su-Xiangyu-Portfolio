2026 · 開源工具 · 28★

Paper Radar

每天早上讀完 arXiv 上所有新論文，只把你該讀的那幾篇挑出來。

  • 用白話寫下研究興趣，模型對每篇論文、每個興趣回答一個是非題並給出校準過的機率，程式再依門檻決定必讀、可讀或略過。
  • 實測 501 篇論文 33 秒判讀完成，花費 $0.02；讀完整個 arXiv 每天約 $0.06。
  • 在四份從未看過的 Cochrane 系統性回顧上篩選 19,447 筆文獻，找回 96.9% 審查者納入的研究，同時減少 78% 的閱讀量。
  • 完全跑在 GitHub Actions + GitHub Pages，輸出網頁與 RSS，可推送到 Slack、Discord、Telegram；fork 即可使用，不需伺服器。
  • Python
  • GitHub Actions
  • RSS
  • LLM 評估
  • 校準

2025 · LINE Bot

停車神隊友

在 LINE 傳出你的位置，馬上知道附近哪裡還有車位。

  • 分享定位或直接輸入地址，就能查詢方圓 2.5 公里內的停車場或路邊停車格，依距離排出最近的 5 個。
  • 串接交通部 TDX 取得即時剩餘車位與收費資訊；資料不足時改用地方政府開放資料補上。
  • 用 Google Geocoding 解析地址，用 Distance Matrix 算出實際開車距離與時間。
  • 結果以 LINE Flex Message 卡片呈現，點一下就開啟 Google 地圖導航；另外提供 LIFF 頁面，並加上流量限制保護 API 額度。
  • Node.js
  • Express
  • LINE Messaging API
  • LIFF
  • TDX API
  • Google Maps API
