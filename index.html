Paper Radar

每天早上讀完 arXiv 上所有新論文，只把你該讀的那幾篇挑出來。

  • 33 秒判讀 501 篇論文
  • $0.06每天讀完整個 arXiv
  • 96.9%系統性回顧召回率
  • 用白話寫下研究興趣，模型對每篇論文回答是非題並給出校準過的機率，程式再依門檻分成必讀、可讀或略過。
  • 在四份未看過的 Cochrane 系統性回顧上篩選 19,447 筆文獻，找回 96.9% 審查者納入的研究，同時減少 78% 閱讀量。
  • 完全跑在 GitHub Actions + Pages，輸出網頁與 RSS，可推送到 Slack、Discord、Telegram；fork 即用，不需伺服器。
  • Python
  • GitHub Actions
  • RSS
  • LLM 評估
  • 機率校準
